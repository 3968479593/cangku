# AI 电商选品助手 —— 项目目录结构详解

## 项目根目录

```
ai电商选品助手/
│
├── run.py                          # 一键启动脚本，subprocess 同时拉起前后端
├── README.md                       # 项目说明、技术栈、启动步骤
├── 项目详解文档.md                  # 万字详细技术文档（含架构图、API表、设计决策）
├── gen_ppt.py                      # PPT 生成器（渲染引擎，23种幻灯片类型）
├── ppt_content.py                  # PPT 内容数据（20页幻灯片的所有文本定义）
├── generate_ppt.py                 # 旧版 PPT 生成器（内容硬编码版，已弃用）
│
├── backend/                        # ──── 后端 ────
│   ├── .env                        # 环境变量：MySQL密码、LLM_API_KEY、模型路径
│   └── requirements.txt            # Python 依赖清单
│   │
│   ├── app/                        # │ 应用主目录
│   │   ├── main.py                 # │ FastAPI 入口：创建app、挂载路由/CORS、启动时预加载BGE-M3模型
│   │   ├── config.py               # │ 配置中心：Pydantic Settings 从 .env 加载所有配置项
│   │   │
│   │   ├── api/                    # │ │ API 路由层（对外接口）
│   │   │   ├── deps.py             # │ │ FastAPI 依赖注入（数据库会话等）
│   │   │   └── routes/
│   │   │       ├── chat.py         # │ │ 🟢 核心：AI对话接口。智能分流(分析/闲聊)、多轮记忆(uuid4)、追问注入上文、品类过滤、输出格式化
│   │   │       ├── search.py       # │ │ 🔍 语义检索接口。POST /api/search -> BGE-M3向量检索+重排序 -> 返回匹配度%
│   │   │       ├── products.py     # │ │ 🛒 商品列表接口。GET /api/products 支持品类/平台/价格筛选分页
│   │   │       └── documents.py    # │ │ 📄 文档管理接口。上传/列表/删除，支持PDF/CSV/XLSX/TXT
│   │   │
│   │   ├── core/                   # │ │ 核心算法引擎（RAG 管道六步）
│   │   │   ├── embedding.py        # │ │ ① 嵌入层：BGE-M3 768维密集向量 + 稀疏词权重编码
│   │   │   ├── vector_store.py     # │ │ ② 向量库：ChromaDB HNSW索引，Cosine相似度，本地持久化
│   │   │   ├── retriever.py        # │ │ ③ 检索层：密集+稀疏并行召回 Top-20（RRF融合代码就绪）
│   │   │   ├── rrf.py              # │ │ ④ RRF融合：倒数排名融合算法（待启用）
│   │   │   ├── reranker.py         # │ │ ⑤ 重排序：bge-reranker-v2-m3 Cross-encoder精排 + transformers兼容补丁
│   │   │   ├── llm.py              # │ │ ⑥ 生成层：OpenAI兼容接口，3次重试+指数退避，双模式Prompt(前景/简要)
│   │   │   └── document_processor.py # │ │ 文档解析：PDF(PyPDF2)/Excel(openpyxl)/CSV(pandas)/TXT
│   │   │
│   │   ├── models/                 # │ │ 数据模型层
│   │   │   ├── database.py         # │ │ SQLAlchemy 引擎+会话工厂，连接 MySQL
│   │   │   ├── product.py          # │ │ Product ORM：12字段（名称/品类/价格/平台/销量/评分/描述等）
│   │   │   ├── document.py         # │ │ Document + Chunk ORM：文档元数据+分块记录
│   │   │   └── schemas.py          # │ │ Pydantic 模型：ProductOut/ChatRequest/ChatResponse/SearchResult
│   │   │
│   │   ├── services/               # │ │ 业务逻辑层
│   │   │   ├── retrieval.py        # │ │ 检索服务：编排粗排(向量) -> 精排(Cross-encoder) -> 失败降级
│   │   │   ├── ingestion.py        # │ │ 入库服务：解析 -> 分块 -> 嵌入 -> 双写 ChromaDB + MySQL
│   │   │   ├── statistics.py       # │ │ 统计服务：全量品类聚合(均价/均销量/Top10/低分预警/平台分布) + 关键词映射
│   │   │   └── recommendation.py   # │ │ 推荐服务：选品推荐算法逻辑
│   │   │
│   │   └── utils/                  # │ │ 工具
│   │       ├── chunker.py          # │ │ 智能分块：512字符+100重叠，自然分隔符断句，死循环防护
│   │       └── logger.py           # │ │ 日志：统一日志格式配置
│   │
│   ├── models/                     # │ 本地AI模型文件（HuggingFace下载）
│   │   ├── BAAI/bge-m3/            # │ BGE-M3 嵌入模型（768维，中英多语言）
│   │   └── BAAI/bge-reranker-v2-m3/ # │ BGE-Reranker 重排序模型
│   │
│   ├── data/                       # │ 数据目录
│   │   ├── products.csv            # │ 商品数据（365条 × 12品类 × 3平台 × 4季节）
│   │   ├── uploads/                # │ 用户上传的文档存放处
│   │   └── chroma_db/              # │ ChromaDB 向量库持久化文件
│   │
│   ├── scripts/                    # │ 运维脚本
│   │   ├── init_db.py              # │ 初始化 MySQL 数据库表结构
│   │   ├── import_products.py      # │ 导入商品CSV -> BGE-M3嵌入 -> ChromaDB + MySQL双写
│   │   ├── download_models.py      # │ 预先下载 BGE-M3 / bge-reranker 模型到本地
│   │   ├── offline_ingest.py       # │ 离线批量导入文档（不通过API）
│   │   ├── expand_products.py      # │ 商品数据扩充（121 -> 300条，品类均衡化）
│   │   └── add_seasons.py          # │ 补充四季商品（冬/春/秋装，解决"冬天穿啥"搜不到的问题）
│   │
│   └── tests/                      # │ 测试代码
│
├── frontend/                       # ──── 前端 ────
│   ├── .env                        # 前端环境变量（VITE_API_BASE等）
│   ├── index.html                  # HTML 入口文件
│   ├── package.json                # Node.js 依赖：Vue3 + Vite + vue-router
│   ├── vite.config.js              # Vite 构建配置：开发端口:5173、API代理到:8000
│   └── src/
│       ├── main.js                 # Vue 应用入口（createApp + router）
│       ├── App.vue                 # 根组件（单文件SPA，导航栏 + 页面路由）
│       ├── router/index.js         # 路由配置：/ -> Home, /search -> Search, /chat -> Chat, /documents -> Documents
│       └── views/
│           ├── Home.vue            # 🏠 首页：项目介绍 + 快捷入口
│           ├── Search.vue          # 🔍 搜索页：自然语言输入 -> 结果卡片(商品名/品类/价格/平台/销量/匹配度%)
│           ├── Chat.vue            # 💬 对话页：多轮对话界面 + 快捷提问标签 + white-space:pre-wrap 渲染
│           └── Documents.vue       # 📄 文档管理：上传(拖拽) + 文档列表(名称/类型/状态/分块数) + 删除
│
└── chroma_db/                      # 项目根目录下的旧Chromadb数据（已迁移到backend/data/chroma_db/）
```

## 关键数据流

```
👤 用户提问（自然语言）
    │
    ▼
[chat.py]  智能分流 ──→ 分析类问题 ──→ [statistics.py] 全量品类聚合统计
    │                      │                      │
    │                      ▼                      ▼
    │              [retrieval.py]         品类均值/Top10/预警
    │              稠密向量检索 Top-20           │
    │                      │                   │
    │                      ▼                   │
    │              [reranker.py]               │
    │              Cross-encoder 精排 Top-5     │
    │                      │                   │
    │                      ▼                   │
    │              上下文拼接 ◄─────────────────┘
    │                      │
    │                      ▼
    │              [llm.py]  LLM 生成
    │              方式A: 五段深度分析
    │              方式B: 简要回答
    │                      │
    │                      ▼
    │              [_format_output()]  强制格式化
    │                      │
    ▼                      ▼
  💬 前端渲染（white-space: pre-wrap）
```

## 数据规模

| 指标 | 数值 |
|------|------|
| 商品总数 | 365 条 |
| 品类数 | 12 个（每品类25-30条） |
| 平台数 | 3 个（抖音/拼多多/小红书） |
| 季节覆盖 | 4 季（春夏秋冬） |
| 价格区间 | 4.9元 ~ 259元 |
| 销量区间 | 6,500件 ~ 72,500件 |
| REST API | 8 个端点 |
| 前端页面 | 4 个 |
| 嵌入模型 | BGE-M3（768维） |
| 向量库 | ChromaDB（HNSW索引） |
